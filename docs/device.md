# Устройство: Samsung Galaxy S8 (SM-G950F)

## Общие характеристики

- Модель: SM-G950F (международная версия)
- Кодовое имя (Samsung/AOSP): dreamlte
- SoC: Samsung Exynos 8895 (10 нм)
  - CPU: 4×Exynos M2 "Mongoose" (до ~2.3 ГГц) + 4×Cortex-A53 (до ~1.7 ГГц), big.LITTLE
  - GPU: ARM Mali-G71 MP20 (архитектура Bifrost, gen1)
- RAM: 4 ГБ LPDDR4
- Встроенная память: 64 ГБ UFS 2.1 (+ слот microSD)
- Экран: 5.8", 2960×1440, Super AMOLED, DSI-панель
- Связь: интегрированный Exynos-модем, Wi-Fi, Bluetooth, NFC

## Текущее состояние устройства

- Разблокированный загрузчик, установлен TWRP.
- Остались файлы/следы незавершённых попыток установки Windows 11 ARM —
  планируется стереть после TWRP-бэкапа, как только начнём практические
  работы по [boot-chain.md](boot-chain.md) (план A уже не требует ожидания
  внешних источников).
- Данные из текущих попыток физически лежат на разделе с Windows — можно
  стирать телефон после того, как нужное будет скопировано/сохранено вне
  устройства.

## Известные сложности для Samsung/Exynos устройств

- Samsung публикует opensource-ядро для SM-G950F через opensource.samsung.com
  (по требованиям GPL), но это, как правило, устаревшая даунстрим-ветка
  (Android kernel 4.4.x), а не что-то близкое к mainline.
- Exynos 8895 получил минимальную поддержку в mainline Linux (kernel.org) в
  2024 году — но только базовые CPU/pinctrl/GPIO/framebuffer, без
  тачскрина, звука, WiFi/BT, GPS, камер и т.д. Подробности и источники —
  см. [prior-art.md](prior-art.md).
- Secure Boot / Samsung KNOX потенциально может блокировать нестандартные
  загрузочные образы — зависит от того, что уже произошло с загрузчиком в
  рамках текущих попыток с Windows 11 ARM и TWRP.

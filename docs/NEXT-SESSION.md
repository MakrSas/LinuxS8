# Промпт для следующей сессии

Полная передача дел — в `docs/HANDOFF.md`. Этот файл только промпт.

---

```
Проект: Debian с графическим окружением на Samsung Galaxy S8 (SM-G950F,
Exynos8895), рабочая папка — корень локального клона.

Прочитай docs/HANDOFF.md целиком — там всё: состояние, метод работы с
устройством, что уже измерено, открытые задачи и список граблей. Раздел 7
про грабли прочитай особенно внимательно, каждая из них стоила вечера.

Остальную документацию читай по мере надобности: docs/graphics.md и
docs/ufs-bringup.md — подробности по подсистемам, docs/progress-log.md —
хронология.

Меня не надо спрашивать перед перепрошивкой и перезагрузкой телефона —
делай сразу. Спрашивай только когда нужно физическое действие: зайти в
TWRP, переткнуть кабель, посмотреть на экран.

Если надо в интернет через терминал:
export HTTP_PROXY=http://127.0.0.1:10809 HTTPS_PROXY=http://127.0.0.1:10809

Для чистой установки сначала читай docs/INSTALL.md и проверяй scripts/installer.py.
Он должен ждать TWRP, запросить имя/пароль аккаунта, подтвердить FORMAT sda29 и
FLASH sda7, а масштаб Phosh по умолчанию выставить 300%.

Всё существенное пиши в docs/progress-log.md по ходу дела.
```

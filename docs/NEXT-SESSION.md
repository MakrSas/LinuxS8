```
Проект: Debian + GNOME на Samsung Galaxy S8 (SM-G950F, Exynos8895), рабочая
папка /home/makr/Documents/LinuxS8.

Сначала прочитай docs/ufs-bringup.md целиком — там самодостаточное описание
задачи, что уже сделано, что сломано, аппаратные факты, команды и грабли.
Потом README.md для общей картины.

Текущая задача: доделать bring-up внутренней памяти (UFS), чтобы отвязаться
от microSD и перенести Debian на внутренние 34.5 ГБ.

Где остановились: драйвер доходит до старта линка UniPro и упирается ровно в
одну ошибку — "uic cmd 0x16 with arg3 0x0 completion timeout", то есть
DME_LINK_STARTUP не завершается. Отказов атрибутов больше нет ни одного,
контроллер включается, все наши правки приняты. Осталась физика линка, и
подозрение сузилось до PHY: у нас стоит шаблон samsung,exynos7-ufs-phy от
Exynos7420 с чужой таблицей калибровки, непроверенным смещением регистра
изоляции в PMU (0x724 против дефолтных 0x720) и тремя фиктивными &oscclk
вместо настоящих тактов.

Следующий шаг — раздел 9 в docs/ufs-bringup.md: склонировать даунстрим-ядро
Samsung для universal8895 и достать оттуда настоящую таблицу калибровки PMA,
проверить смещение изоляции и модель тактов PHY. Дальше написать
drivers/phy/samsung/phy-exynos8895-ufs.c по образцу phy-gs101-ufs.c и свой
compatible samsung,exynos8895-ufs-phy.

Телефон сейчас в TWRP, подключён по adb (adb лежит в
build/tools/platform-tools/adb). Прошито boot_prelink.img, модули на карте
синхронизированы, флаг ARMED снят.

Важное про работу с устройством (подробности в docs/ufs-bringup.md, раздел 6):
- экрану телефона верить нельзя, читать только journal с карты через
  scripts/read-journal.sh;
- цикл опыта: scripts/arm-experiment.sh -> adb reboot -> дождаться ->
  телефон в TWRP -> scripts/collect-lab.sh;
- после сборки ядра ОБЯЗАТЕЛЬНО scripts/push-modules.sh, иначе на телефоне
  останутся старые модули;
- прошивку раздела всегда сверять по md5;
- дерево ядра в git не входит, после каждой правки переэкспортировать
  патчи в patches/kernel/.

Меня не надо спрашивать перед перепрошивкой и перезагрузкой телефона —
делай сразу. Пиши всё существенное в docs/progress-log.md и
docs/ufs-bringup.md по ходу дела, чтобы работу можно было продолжить с
любого места.
```

## Чек-лист перед началом следующей сессии

- [ ] телефон в TWRP, `adb devices` показывает `recovery`;
- [ ] `e2fsck -fp /dev/block/mmcblk0p1` перед монтированием карты;
- [ ] есть интернет для `git clone` даунстрим-ядра (~2 ГБ с `--depth 1`).

## Что уже не надо делать

- microSD работает, трогать не нужно;
- Debian и GNOME установлены и настроены;
- тулчейн, uniLoader, ядро, busybox — всё в `build/`, качать заново нечего;
- лаборатория (сервисы сбора логов) установлена на карте.
